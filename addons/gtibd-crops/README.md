# GregCrops addon

Аддон для GregTech: Industrial Brain Damage на Minecraft 1.20.1, Forge 47.4.28 и GregTech CEu Modern 7.5.3. В каталоге 31 ванильная культура и 79 селекционных линий.

## Установка бета-версии

Нужны Minecraft 1.20.1, Forge 47.4.28, Java 17, GregTech CEu Modern 7.5.3 и его обязательные зависимости. Скачайте [JAR GregCrops 0.1.0](../../pack/overrides/mods/gregcrops-addon-0.1.0.jar?raw=true) и положите его в папку `mods`. Для отдельного профиля этого достаточно. Рецепты жердей, ножа, двух машин LV и переработки урожая входят в JAR. У выделенного сервера поставьте JAR на сервер и на клиенты.

В GregTech: Industrial Brain Damage скопируйте [скрипт рецептов сборки](../../pack/overrides/kubejs/server_scripts/gregcrops_progression.js?raw=true) в `kubejs/server_scripts`. Скрипт заменяет встроенные рецепты на варианты с деталями GTIBD. Для выделенного сервера скрипт нужен на сервере.

На выделенном сервере Forge проверены все 83 рецепта, ручной крафт жердей и сборка анализатора в машине GregTech с расходом припоя. Для этого прогона использованы GregTech CEu Modern и GregCrops. SHA256 проверенного JAR: `f8092851f9a9e222816740aaa205ab1f6e33118344d79dd97677b7521c1ecccc`.

## Жерди и семена

Поставьте жерди на пашню и высадите обычное семя или пакет с семенами GregCrops. Для скрещивания положите вторые жерди на пустые первые и вырастите две подходящие культуры по соседству. Растениям нужны свет, влажная пашня и подходящий блок под ней, если его требует вид. Параметры роста, урожайности и устойчивости передаются потомству.

Срез зрелого растения ножом возвращает семена с их параметрами. Анализатор показывает параметры живого растения при щелчке по жердям. Для анализа пакета держите его во второй руке и используйте анализатор три раза.

## Сборщик LV

Ставьте машину на высоте жердей. Она проверяет участок 9×9 с центром в машине, принимает до 32 V и расходует 32 EU на операцию. Урожай можно забирать предметной трубой или воронкой.

- С анализатором машина забирает только плоды. Растение остаётся взрослым на жердях и выращивает новую порцию. Для установки щёлкните по машине анализатором.
- Без анализатора машина забирает срезанные побеги и с вероятностью 25% также собирает плоды. Растение остаётся на жердях и отрастает. Резиновый тростник даёт сахарный тростник и может дать сырой латекс. Остальные культуры дают растительные обрезки для компостера и могут дать свой урожай. Ручной сбор работает так же. Чтобы вынуть анализатор, щёлкните по машине пустой рукой, удерживая Shift.

Урожай ресурсных культур перерабатывается в центрифуге нужной ступени GregTech. Для запуска нужен образец ранее полученного ресурса. Для жидких продуктов также требуется запас соответствующей жидкости.

## Исходники

Рецепты GTIBD находятся в `pack/overrides/kubejs/server_scripts/gregcrops_progression.js`. Каталог культур хранится в `src/main/java/gtibd/crops/CropCatalog.java`. В качестве референсов использованы [реестр GT5 Unofficial](https://github.com/Blood-Asp/GT5-Unofficial/blob/unstable/src/main/java/gregtech/loaders/postload/GT_CropLoader.java#L389-L459), [реестр CropsNH](https://github.com/GTNewHorizons/CropsNH/blob/master/src/main/java/com/gtnewhorizon/cropsnh/loaders/CropLoader.java) и [механика анализатора IC2](https://wiki.industrial-craft.net/index.php?title=Cropnalyzer).

Для сборки под Java 17 укажите путь к JAR GregTech CEu 7.5.3.

```powershell
.\gradlew.bat build "-PgregTechJar=C:/path/to/gtceu-1.20.1-7.5.3.jar"
```
